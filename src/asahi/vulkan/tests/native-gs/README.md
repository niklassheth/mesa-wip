# Native GS stage-2 controls

Default-off `HK_APPLE9_GS_NATIVE=1` also requires `HK_APPLE9_NATIVE_MESH=1`
and explicit `HK_APPLE9_NATIVE_MESH_PACKED_SHAPES=T16V3P1,T16V4P2`.
The API remains GS. The linked native realization owns a software VS, mesh
body, generated taskless object and matching FS. Unsupported state uses the
existing GS realization.

Initial submission scope: one direct, nonindexed triangle-list input,
one instance, zero first vertex/instance, one sample/layer/view, Position-only
GS strips declared V3/P1 or V4/P2. Queries that count work, conditional draws,
XFB, tessellation, extra varyings, GS invocations/streams, adjacency, indirect,
restart, and larger declarations retain fallback. Timestamp commands may
surround draws and retain full dependencies. API limits do not change.

`transitions.c` is an ordinary Vulkan draw/readback control. Build it for the
target with libvulkan; compile `strip.geom` with MAX_VERTICES=3, 4 and 5, plus
`input.vert`, `blue.frag` and `white.frag`, with glslangValidator. The V5
control emits at most four vertices but its declaration must force fallback.
Its arguments are printed on invalid invocation. N uses the selected V3/V4
GS, E the V5 fallback, V a vertex-only white draw, M a red attachment clear.
The GS UBO selects emitted count and strip-ending mask. Use emitted <=3 for
the V3 module. Indexed/instances/offset/indirect modes test draw fallbacks.
The `merged` mode means two API render passes with LOAD continuation; the
software VS dependency can prevent hardware merging.

`record.py` requires an explicit private driver, nonexecuting AArch64 DRM
shim, sysroot, compiled probes and new output directory. It asserts expected
final GS routes and untouched 0xa5 readback. `--cache-dir` enables actual
cross-process shader-cache round trips. No GPU execution is claimed.
`check-records.py` checks the resulting HOST-RECORDS.json inventory and
OFFSETS.json generated by `offsets.c`: software VS dispatch, CDM links and
cache flush, full queue dependencies, mesh/object packets, shared VS output
buffer roots and partial attachment continuation within one API pass.

The independent pixel oracle checks all non-diagonal samples. A future
device runner must additionally compare all 16,384 native/fallback image
bytes, including diagonal edges, and run orientation/culling controls before
claiming strip winding correct. Zero and incomplete counts must leave clear
pixels. A completed mismatch is a failure; no retries or expected-failure
promotion. The control stops and retains backing on uncertain submission or
fence retirement. An external owner must monitor GPU faults and watchdogs,
collect evidence and reset before terminating retained processes.

This source and its device packet are a draft, not a frozen or queued
hardware request. Compiler/routing review and device results remain required.
